# humanizer 只取句法层，主动删除内容与结构层指令

humanizer 的 24 条规则里混着两类指令。一类作用于句子内部：禁用 AI 高频词、拆掉 `-ing` 结尾的假深度、少用加粗、避免空洞的积极结尾。另一类作用于篇章：打乱逻辑顺序、总字数增加 30%、注入 5 处表达不确定性、模拟凌晨三点赶稿。

我们只保留前者，主动删除后者。理由是后者服务于"降低 AI 查重率"这个与本项目无关的目标，会直接摧毁本 skill 的核心卖点"精简干练"——你没法同时做到"字数增加 30%"和"精简干练"。

分工因此变得清晰：humanizer 管句法，Matt Pocock 的文章管内容与结构，两者作用在不同层面，不冲突。

明确记录此决策，是为了防止后来者把被删掉的部分当成遗失内容补回来。
